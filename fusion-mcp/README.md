# fusion-mcp

## install-fusion-mcp.sh

Installs the [Fusion MCP server](https://github.com/PureStorage-OpenConnect/fusion-mcp-server) binary and registers it with one or more AI agents. It also handles updates, pre-release builds, rollback, and removing the server from agents.

### Supported agents

| Key | Agent | Config written |
| --- | --- | --- |
| `claude` | Claude Code CLI | via `claude mcp add` (scope `user` by default) |
| `desktop` | Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| `vscode` | VS Code | `~/Library/Application Support/Code/User/mcp.json` (`~/.config/Code/User/mcp.json` on Linux) |
| `gemini` | Gemini CLI | `~/.gemini/settings.json` |
| `copilot` | GitHub Copilot CLI | `~/.copilot/mcp-config.json` |
| `augment` | Augment | `~/.augment/settings.json` |
| `codex` | Codex CLI | `~/.codex/config.toml` |
| `opencode` | OpenCode | `~/.config/opencode/opencode.json` |

Only the `fusion-mcp` entry is added or replaced. Other servers and settings in each config are left alone. If a config can't be parsed, the script stops with an error instead of overwriting it.

### Requirements

- macOS or Linux, arm64 or x86_64
- `bash`, `curl`, `python3`
- `gh` (optional, used for GitHub API calls when present)
- `claude` on `PATH`, only if configuring Claude Code
- An API token for at least one FlashArray or FlashBlade

### Quick start

```sh
curl -fsSLO https://raw.githubusercontent.com/mikenelson-io/fusion-scripts/main/fusion-mcp/install-fusion-mcp.sh
chmod +x install-fusion-mcp.sh
./install-fusion-mcp.sh
```

With no options, it downloads the latest stable release, asks for array hosts and API tokens to build the auth config, and lets you pick agents from a menu.

### Usage

```sh
./install-fusion-mcp.sh                               # interactive install
./install-fusion-mcp.sh --agents all                  # every supported agent
./install-fusion-mcp.sh --agents claude,desktop,vscode
./install-fusion-mcp.sh --update                      # newer binary + re-apply saved agents
./install-fusion-mcp.sh --update --pre-release        # include pre-release builds
./install-fusion-mcp.sh --file ./fusion-mcp-server-darwin-arm64-v2.0.0-rc3 --agents codex
./install-fusion-mcp.sh --rollback                    # undo the last binary change
./install-fusion-mcp.sh --list-versions               # see rollback targets
./install-fusion-mcp.sh --remove-agent gemini         # unregister from an agent
```

### Options

| Option | Description |
| --- | --- |
| `--agents LIST` | Comma-separated agent keys, or `all`. Omit for the interactive menu (install) or the saved list (`--update`). |
| `--update` | Re-download only if the latest release is newer. Never touches the auth config. Re-applies the saved agents unless `--agents` is given. |
| `--pre-release` | With `--update`, consider pre-release builds too. Without it, only stable releases are used. |
| `--file PATH` | Install from a local binary instead of GitHub, e.g. a pre-release shared out-of-band. It must be executable and respond to `--version`. Takes priority over `--update`. |
| `--rollback [VERSION]` | Restore a backed-up binary: the most recent one, or `VERSION` as shown by `--list-versions`. Agent configs are not touched. |
| `--list-versions` | List backed-up binaries and exit. |
| `--remove-agent LIST` | Remove the server from these agents' configs and drop them from the saved list. Binary and auth config stay. |
| `--binary PATH` | Install location. Default `~/.local/bin/fusion-mcp-server`. Also settable via `FUSION_MCP_BINARY`. |
| `--name NAME` | Server name registered with agents. Default `fusion-mcp`. |
| `--scope SCOPE` | Claude Code MCP scope, `user` or `local`. Default `user`. |
| `-h`, `--help` | Show help. |

### Staying on a pre-release

`--update` compares the installed version with the latest **stable** release. If you're on a release candidate, a plain `--update` will replace it with the stable build. To stay on the pre-release track, use `--update --pre-release`. To re-apply agent configs without touching the binary, point `--file` at the installed binary:

```sh
./install-fusion-mcp.sh --update --file ~/.local/bin/fusion-mcp-server --agents opencode
```

### Files it manages

| Path | Purpose |
| --- | --- |
| `~/.local/bin/fusion-mcp-server` | The server binary every agent points at |
| `~/.config/fusion-mcp/auth-config.json` | Array hosts and API tokens, generated by `fusion-mcp-server generate-config`. **Contains credentials. Keep it private.** |
| `~/.config/fusion-mcp/install-state.json` | Agents you've configured, so `--update` knows what to touch. New agents are added to the list; `--remove-agent` removes them. |
| `~/.local/bin/.fusion-mcp-versions/` | Backups of replaced binaries (last 5) for `--rollback` |

### Notes

- **macOS:** the script clears the Gatekeeper quarantine flag on downloaded binaries. It installs by staged copy and rename, never an in-place overwrite, because overwriting a signed binary in place can make macOS kill it on launch (exit 137, no output).
- **Codex:** reinstalling repairs configs damaged by older versions of this script, which left a stray `["start", "--auth-config", ...]` line in `config.toml`.
- **Restart after changes.** Claude Desktop must be fully quit and relaunched. VS Code can use *MCP: Restart MCP Server*. For CLI agents, start a new session.

Server documentation: [Fusion MCP server user guide](https://github.com/PureStorage-OpenConnect/fusion-mcp-server/blob/main/docs/USER_GUIDE.md)
